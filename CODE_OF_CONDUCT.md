# Code of Conduct

Everyone who takes part in this project, in issues, pull requests, discussions, or reviews, is expected to treat others with respect. **This applies to maintainers as much as to contributors.**

## What Is Expected

- Be kind and patient, especially with someone new to the project.
- Disagree about the work, never about the person.
- Accept a review comment as feedback on the change, and give one the same way.
- Own a mistake, apologise to whoever it affected, and learn from it.
- Put what is best for the people using the project ahead of winning an argument.

## What Is Not Accepted

- Harassment, insults, or personal or political attacks.
- Sexualised language or imagery, or unwanted sexual attention.
- Trolling, or deliberately derailing a conversation.
- Publishing someone's private information, such as an address or an email, without their permission.
- Posting a GitHub token, or any other credential, that belongs to someone else.
- Using this repository's issues, pull requests, or discussions to run the badge automation. Point it at a repository of your own.
- Anything else a reasonable person would consider inappropriate in a professional setting.

## Where It Applies

Every space this project runs: the repository, its issues, pull requests, and discussions, and anywhere someone is acting on behalf of the project.

## How to Report

Report a concern to the maintainer, [@rahfianugerah](https://github.com/rahfianugerah). Every report is reviewed, and the reporter's identity is kept private.

## What Happens After a Report

The maintainer decides the response from what happened and how serious it was:

| Step | When | What happens |
| :- | :- | :- |
| Correction | A one-off lapse | A private message explaining what was wrong |
| Warning | A pattern, or one serious incident | A warning with consequences, and no contact with the people involved for a set time |
| Temporary ban | A serious or repeated breach | No interaction with the project for a set time |
| Permanent ban | Harassment, or a pattern that continues after a ban | No interaction with the project again |
